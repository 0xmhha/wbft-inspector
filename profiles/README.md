# Implementation log profiles

`gstable@740526d03.json` is generated from the complete 184-row public A-13
catalog in `wbft-spec` revision `1c91f50`. Phrases and source locations are
read from that catalog, including duplicate calls and numeric candidates.
The generator maps catalog phrases to the WBFT event vocabulary; entries
without an observable state transition use `HEALTH`. A handling log does
not assert successful receipt, and a send log does not prove a wire write.

```sh
python3 tools/logprofile/generate.py ../wbft-spec/spec/A-13-appendix.md
python3 tools/logprofile/generate.py ../wbft-spec/spec/A-13-appendix.md --check
```

This is data for log adapters. The current inspector `internal/logs`
adapter still accepts the `wbft@` profile generated by `wbft-logprofile`;
legacy normalization and its independent checker integration are not yet
implemented there. Do not treat publishing this profile as I2 completion.
